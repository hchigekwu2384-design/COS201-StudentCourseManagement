COS201 Student Course Management System

Project Overview

The Student Course Management System is a Java console application developed for the COS201 Programming I assessment.

Features

- Add new courses
- View all recorded courses
- Search for courses by course code
- Calculate total credit units
- Save course records to a text file
- Load saved courses from a text file
- Input validation and exception handling

Technologies Used

- Java
- Visual Studio Code
- Git and GitHub

How to Run

1. Install the Java Development Kit (JDK).

2. Open the project folder in VS Code.

3. Open the terminal.

4. Compile the program:
   
   "javac Main.java Course.java"

5. Run the program:
   
   "java Main"
